# Vector exercises

Part of [C and C++ Learning](../README.md), built with the root CMake project.

| Source | Target | Focus |
| --- | --- | --- |
| `Vector.cpp` | `VectorBasics` | Basic container operations |
| `operation_vector.cpp` | `VectorOperations` | Iteration and element-wise operations |
| `sortt.cpp` | `VectorArithmetic` | Arithmetic on vector elements; the filename is historical |
| `solve1.cpp` | `VectorGrades` | Sorting grades, mean and median, with input validation |

Use the build and test commands in the root README. `VectorGrades` prompts for a student count, a grade count, then each student's name and grades. Names are entered as a single word.
