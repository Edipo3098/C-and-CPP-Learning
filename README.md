# C and C++ Learning Exercises

Practice repository covering data structures, pointers, classes, preprocessor techniques and basic mathematical transformations.

- [C/C++ practice projects](Proyects-Cpp/README.md): five projects organized with CMake, including structures and pointers, a car/motor class, 2D rotation, unions and X-macros.
- [Vector exercises](Vector/): earlier C++ vector and sorting exercises.

See each directory for its source and build instructions. These are learning exercises, with implementation limitations documented where identified.
